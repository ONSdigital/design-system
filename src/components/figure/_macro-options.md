| Name                 | Type                | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------------- | ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| useDivForRootElement | boolean             | false    | If `true`, renders the root element as a `div` instead of a `figure`. When set, the caption renders in a `span` instead of a `figcaption`.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| headingLevel         | number              | false    | Number used to determine the heading level of the title. The subtitle is rendered one level below this, e.g. if you provide level 3, the subtitle will render as h4. The download and footnotes heading levels adjust based on which headings are present: two levels below when both title and subtitle are provided, one level below when only title is provided, or at the base heading level when neither is provided. Accepts a value between 1 and 4, defaulting to 2 if not provided. All headings render at a fixed visual size regardless of the level chosen. |
| title                | string              | true     | The title displayed above the nested content.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| subtitle             | string              | false    | The subtitle displayed below the title. Only rendered when `title` is also provided.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| audioDescription     | string              | false    | A visually-hidden textual description of the nested content for screen readers, associated with the figure via `aria-describedby`. Should not be used when nesting an image as the alt-text on the image serves this purpose instead.                                                                                                                                                                                                                                                                                                                                   |
| caption              | string              | false    | A short visible caption providing additional context, displayed in a `figcaption`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| footnotes            | `Object<Footnotes>` | false    | Footnotes to appear below the nested content in a 'details' element.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| download             | `Object<Download>`  | false    | Object for [download](#download) options, displayed in a details element below the nested content.                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

| id | string | true if audio description, footnotes or downloads provided | An `id` applied to the wrapping element. Also used to generate the audio description, footnotes and downloads `ids`. |
| classes | string | false | Classes to add to the wrapping element. |

The nested content (for example a [chart](/components/chart) or [image](/components/image)) is provided through the macro's `caller` block rather than as a parameter, so no HTML needs to be passed in. See the example for usage.

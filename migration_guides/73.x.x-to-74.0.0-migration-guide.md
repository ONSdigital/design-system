# Migration Guide from version 73.x.x to 74.0.0

# Introduction

This document outlines the steps needed to migrate to version 74.0.0 of our Design System library from versions 73.x.x. This release includes several breaking changes that may impact your projects. Please follow this guide to ensure a smooth transition.

## Base template and global changes

This section will list the changes to the base template and changes that affect more than one component.

### **_Mark up changes to improve accessibility and semantics_**

[**Link to PR 1**](https://github.com/ONSdigital/design-system/pull/3824)

[**Link to PR 2**](https://github.com/ONSdigital/design-system/pull/3876)

-   **Overall description of changes including non-breaking changes:**

    -   The `<main>` tag has been moved higher up the tree to ensure that all content is rendered inside a landmark element ([W3.org reference](https://www.w3.org/WAI/WCAG21/Techniques/aria/ARIA11.html))

    -   The breadcrumbs have been moved so that they render inside the `<header>` tag as this is more semantically correct.

    -   The `<preMain>` block has been moved so that it still renders before the `<main>` tag

    -   Instructions added for any blocks that are rendered outside of an existing landmark to explain that they must use a landmark level element

    -   The 'main' block has been renamed to 'mainContent'

    -   New breadcrumbs block created

    -   New hero block created

    -   New preBreadcrumbs block created

    -   New postHero block created

-   **Migration steps for renaming the `main` block to `mainContent`:**

    1. Locate everywhere in your codebase that you override the `main` block
    2. Update this to use `mainContent`

    ```nunjucks
    OLD

    {% block main %}

    NEW

    {% block mainContent %}
    ```

-   **Migration steps for the `preMain` block:**

    1. Locate everywhere in your codebase that you override the `preMain` block.
    2. Ensure it is using a base element with a landmark level role such as `<section>` - [MDN guide](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/landmark_role).
    3. If necessary, add container classes, as it is no longer rendered inside an element with the container classes set

    ```nunjucks
    OLD

    {% block preMain %}
    <div>...</div>
    {% endblock %}

    NEW
    {% block preMain %}
    <section class="ons-container">...</section>
    {% endblock %}
    ```

-   **Migration steps the `breadcrumbs` and `hero`:**

    1. Locate everywhere in your code base that you override the breadcrumbs and / or add a hero
    2. Move them to their individual blocks

    ```nunjucks

    OLD

    {% block pageContent %}
    {{
        onsBreadcrumbs({
            "ariaLabel": 'Breadcrumbs',
            "variant": "pale-blue",
            "itemsList": [
                {
                    "url": '/',
                    "text": 'Home'
                },
                {
                    "url": '/',
                    "text": 'Business, industry and trade'
                },
                {
                    "url": '/',
                    "text": 'Retail industry'
                }
            ]
        })
    }}
    <main id="main-content">
        {{
            onsHero({
                "title": 'Design and build digital services for the ONS',
                "text": 'Everything you need to make accessible, consistent digital products',
                "button": {
                    "url": '#0',
                    "text": 'Get started'
                }
            })
        }}

        ...Other page content
    </main>
    {% endblock%}

    NEW

    {% block breadcrumbs %}
        onsBreadcrumbs({
            "ariaLabel": 'Breadcrumbs',
            "variant": "pale-blue",
            "itemsList": [
                {
                    "url": '/',
                    "text": 'Home'
                },
                {
                    "url": '/',
                    "text": 'Business, industry and trade'
                },
                {
                    "url": '/',
                    "text": 'Retail industry'
                }
            ]
        })
    {% endblock %}

    {% block hero %}
        {{
            onsHero({
                "title": 'Design and build digital services for the ONS',
                "text": 'Everything you need to make accessible, consistent digital products',
                "button": {
                    "url": '#0',
                    "text": 'Get started'
                }
            })
        }}
    {% endblock %}

    {% block mainContent %}
        ...Other page content
    {% endblock %}

    ```

### **_Breadrumbs_**

**Added new `fullWidth` and `wide` parameters**

[**Link to PR**](https://github.com/ONSdigital/design-system/pull/3824)

-   **Description of change:** The breadcrumbs have 2 extra parameters: `fullWidth` and `wide`
-   **Reason for change:** The breadcrumbs were previously rendered inside a div with the `ons-container` class in the base template, which already had the correct width options applied. Now that they are rendered inside the `<header>` they must set their own `ons-container` class, so need to have these options passed down to ensure their overall width is correct, via the `ons-container--wide` and `ons-container--full-width` classes.
-   **Components impacted:** Breadcrumbs component
-   **Migration steps:**

    1. Locate everywhere in your codebase where you override the breadcrumbs
    2. If you are using either `wide` or `fullWidth` in your `pageConfig`, update the breadcrumbs to match

    ```nunjucks

    OLD example for sites where `wide` is set to true in the `pageConfig`. No customisaiton of the breadcrumbs override necessary.

    {{
        onsBreadcrumbs({
            "ariaLabel": 'Breadcrumbs',
            "variant": "pale-blue",
            "itemsList": [
                {
                    "url": '/',
                    "text": 'Home'
                },
                {
                    "url": '/',
                    "text": 'Business, industry and trade'
                },
                {
                    "url": '/',
                    "text": 'Retail industry'
                }
            ]
        })
    }}

    NEW example for sites where `wide` is set to true in the `pageConfig`. Breadcrumbs override updated to match.

    {{
        onsBreadcrumbs({
            "wide": true,
            "ariaLabel": 'Breadcrumbs',
            "variant": "pale-blue",
            "itemsList": [
                {
                    "url": '/',
                    "text": 'Home'
                },
                {
                    "url": '/',
                    "text": 'Business, industry and trade'
                },
                {
                    "url": '/',
                    "text": 'Retail industry'
                }
            ]
        })
    }}
    ```

    [**See full example**](src/components/breadcrumbs/example-breadcrumbs-wide.njk)
